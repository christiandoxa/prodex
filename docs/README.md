# Documentation Index

This index identifies canonical ownership and lifecycle. Version/date means the
document was checked against that Prodex release or checkout, not that every
external dependency was refreshed on that date.

Status values:

- `active`: maintained source of truth;
- `generated`: regenerated by a repository command;
- `ADR`: accepted decision record;
- `historical`: retained evidence, not current guidance;
- `superseded`: use the named replacement.
