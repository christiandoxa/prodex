# Prodex 0.428.0

## New Features

- Add `prodex_session_preempt` for one exact existing plain `prodex s` session.
- Drain pending prompts through Codex app-server queue controls and interrupt the
  proved active turn without killing the session process.

## Bug Fixes

- Keep session prompt writes and preemption fail-closed when target identity,
  queue state, or turn state is ambiguous.
- Document the exact app-server controls used for thread verification, active
  turn discovery, interruption, and pending queue deletion.

## Changelog

- Release 0.428.0 with the session preemption control-plane surface and its
  offline regression coverage.
