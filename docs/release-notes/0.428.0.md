# Prodex 0.428.0

## New Features

- Adds audited compatibility evidence for Codex rust-v0.154.0 and preserves the
  existing no-replay, fail-closed control-plane boundary.

## Bug Fixes

- Gates quota-window observations on an actually permitted, current window so
  denied or exhausted accounts cannot be scored as normally eligible.
- Rolls back provisional browser Redis shadow state when persistence reports an
  error or a rejected write, while preserving ownership checks and bounded
  capacity behavior.
- Hardens broker process identity and bounded legacy-registry recovery, including
  malformed or truncated state handling without weakening containment checks.
- Preserves sidecar backup data when cleanup fails and rejects inverted Presidio
  analyzer ranges before arithmetic on blocking and asynchronous paths.
- Preserves safe Anthropic request metadata without forwarding credentials or
  transport-local headers.

## Upgrade Notes

- Codex rust-v0.154.0 compatibility evidence in this release is source- and
  offline-queue-scoped; it does not claim live provider, reconnect, or resume
  execution.
- Redis-backed persistence remains bounded and ownership-aware; distributed
  Redis commit ambiguity and pre-existing remote ownership races are not treated
  as distributed atomicity guarantees.
