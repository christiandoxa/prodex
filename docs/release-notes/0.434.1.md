# Prodex 0.434.1

## New Features

- Advance the audited Codex compatibility target to `rust-v0.159.2`, retaining
  GPT-6.1 Sol as the current upstream bundled/Bedrock default and recognizing its
  872,000-token maximum context in Prodex runtime and Smart Context policy.
- Continue the Rust-to-Mojo hard-replacement train across Gemini Code Assist and
  request contents, Kiro Anthropic/chat message shaping, DeepSeek request
  planning, and Copilot request policy without reintroducing Rust semantic
  fallbacks for those migrated surfaces.
- Track Codex 0.159.2's centralized background-process launch contract so future
  upstream drift in Windows console suppression fails the compatibility guard.

## Bug Fixes

- Accommodate Codex 0.159.2's Windows fix that prevents console windows flashing
  when background processes and sandboxed commands are launched.
- Refresh the standalone-release Kiro CLI pin from 2.25.0 to 2.26.0 so the
  release-cut freshness gate follows the current stable manifest instead of
  rejecting an otherwise valid build.
- Add the missing curated 0.434.1 release notes required by the publish workflow
  before it is allowed to create the release tag.

## Codex 0.159.2 Compatibility

- Exact 0.159.1-to-0.159.2 tagged-source comparison covers 47 changed files,
  387 additions, and 76 deletions.
- `codex_utils_process::background_command` now centralizes `CREATE_NO_WINDOW`
  for Windows background commands while preserving ordinary process construction
  on non-Windows platforms.
- Redirected shell-tool children use the console-free background helper;
  inherited/interactive stdio retains normal launch behavior.
- Existing Responses HTTP/WebSocket, provider-authentication, quota/error,
  project-trust, session, GPT-6.1 Sol model metadata, and app-server lifecycle
  compatibility markers replay with zero misses.
- Official 0.159.2 Linux musl CLI and app-server assets match their published
  SHA-256 digests, the CLI reports `codex-cli 0.159.2`, and an isolated
  app-server initialize smoke succeeds.

## Verification

- Upstream compatibility baseline replay: zero missing existing markers plus new
  Windows background-process markers.
- Official Codex 0.159.2 source, CLI, and app-server checksums: verified.
- Isolated Codex 0.159.2 app-server initialize handshake: accepted.
- Upstream baseline guard and self-test: pass.
- Release workflow Kiro 2.26.0 manifest pin and installer hash: verified.
