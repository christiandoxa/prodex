# Prodex 0.420.0

## New Features

- Expanded the Mojo-native deterministic core across runtime policy and
  selection, provider transformations, gateway and control-plane planning,
  application plans, context classification, and domain accounting while
  retaining Rust-owned host and transport boundaries.
- Improved runtime recovery with bounded probe budgets, temporary local
  saturation recovery, and continuation of usage-limited sessions.

## Bug Fixes

- Fixed automatic DeepSeek recovery when native Anthropic web-search
  translation is incompatible with a request, while preserving explicit mode
  semantics and sending the request only once upstream.
- Fixed Windows process-handle handling for optional PTY-backed launches and
  bounded local-capacity recovery tests.
- Kept default lint, Sonar, Mojo self-test, and release-size paths clean across
  the final release validation train.
