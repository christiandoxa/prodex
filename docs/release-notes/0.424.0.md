- Await nested Node threshold tests so every release-floor case executes and
  reports truthful JSON/check results.
- Split Unix secure-file validation without changing symlink, special-file,
  permission, or managed-secret semantics.
- Synchronize Windows listener readiness and accept legitimate websocket
  shutdown after closure begins, while keeping non-closure errors visible.
- Isolate Claude import fixtures from real developer homes and preserve
  test-controlled `CLAUDE_CONFIG_DIR` security coverage.
- Accept a positive Cargo test run followed by an auxiliary zero-test harness
  without weakening true zero-test rejection.
- Resolve optional-tool freshness against stable semver releases, including
  Caveman `2.5.0` and RTK `0.47.0`, and refresh the Kiro stable pin to `2.21.0`.
