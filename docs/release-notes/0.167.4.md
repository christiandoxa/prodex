# Prodex 0.167.4

## Local saved-session continuity

- Keep profileless local-adapter identities distinct from deleted user-managed
  profiles when saving runtime state and continuation sidecars.
- Permit explicit Offrail/Bonsai CLI launches to replay client-supplied history
  despite historical session-only binding tombstones. Preserve provider and
  endpoint enforcement for opaque response IDs, turn state, hosted providers,
  and gateway traffic.
- Record translated Responses IDs instead of raw Chat Completions payloads.
- Use the supplied full local transcript directly instead of appending cached
  reasoning from prior tool calls a second time. Retain exact cached history for
  delta-only tool replies and opaque response continuations.

## Reasoning, tools, and transcript logs

- Open and close real reasoning items around streamed summaries; maintain stable
  item IDs, output indexes, and final response ordering for reasoning, answers,
  and tools.
- Preserve plaintext reasoning when Codex replays a saved chat or returns tool
  results. Continue rejecting opaque encrypted reasoning and malformed content
  instead of dropping or inventing it.
- Let newly discovered log transcripts replay a bounded complete-line tail so
  short reasoning turns are not skipped between discovery ticks.

## Authenticated local and tunneled endpoints

- Accept `--api-key` with `--url`, before or after a resume UUID, and support
  `PRODEX_LOCAL_API_KEY` as the local-only environment fallback.
- Forward only the selected local key for Chat Completions, generic Responses,
  and compaction; keep model catalog discovery local. Preserve unauthenticated
  loopback use without leaking a cloud account credential into local traffic.
- Keep keys out of generated Codex configuration, session state, child-process
  environment, and diagnostics. Reject empty/malformed keys without echoing them.
- Do not follow local upstream redirects; retain authentication failure status
  and endpoint/credential identity boundaries for opaque continuations.

## Compatibility

- Retain explicit local model selection and context/compaction budgets in fresh
  and resumed Super sessions, including the private native app-server path.
- Keep automatic RTK, Codebase Memory MCP, Playwright MCP, and Ponytail activation;
  Presidio remains an interactive consent choice.
- Local OpenAI API interoperability does not imply hosted-model capability or
  quality equivalence. Use the context capacity configured on the local server.
- See [Local Models](../../LOCAL.md) for the complete launch and resume commands.
