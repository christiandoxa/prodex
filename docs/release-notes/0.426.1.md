# Prodex 0.426.1

## New Features

- None.

## Bug Fixes

- `@pdx` now prefers exactly one compatible active plain `prodex s`, injects
  into that session, and reads output from the same returned session and
  cursor. Fresh idle `prodex s` sessions are addressable before any manual
  first prompt through the live Codex app-server bridge.
- A new Prodex Super worker is created only after authoritative `no_session`;
  ambiguity, stale identity, addressability, queue, source, and verification
  errors fail closed without starting a fallback worker.
- Kiro imported/account catalog models now appear in the interactive Super
  sub-agent model picker. Static fallback remains safe, and no
  hard-coded account-specific model list is used.

## Compatibility

- Kiro native `model_id`/`model_name` and ACP `modelId`/`name` catalog shapes
  are normalized to the persisted model IDs.
- Dynamic Kiro models remain suggestions; they do not become an allowlist.
