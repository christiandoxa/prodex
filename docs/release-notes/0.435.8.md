# Prodex 0.435.8

- `prodex ping openai` now asks for the OpenAI model and reasoning effort in a dedicated Ratatui **Prodex Ping** picker before sending interactive probes.
- Added `--effort LEVEL` alongside `--model MODEL`; explicit values skip the matching picker, and the chosen effort is validated against the selected OpenAI model before launch.
- `--json` and non-interactive invocations remain prompt-free for automation, while human and JSON diagnostics now report the requested reasoning effort.
- Ping probes pass the selected effort through the canonical Codex path as `model_reasoning_effort` without changing profile pinning, cross-profile fallback isolation, or typed failure handling.
