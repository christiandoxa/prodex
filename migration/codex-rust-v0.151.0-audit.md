## Upstream ownership decisions

Codex owns conversation reconstruction, compaction internals, tool-call persistence, model
request construction, protocol error formatting, and native TUI/app-server semantics. Prodex
owns profile selection, quota-aware routing, canonical quarantine, Expose, and the child/session
continuity extension around an already persisted Codex session. Prodex does not replay a fresh
prompt as a replacement for `exec resume`, and does not reimplement Codex's internal history.

## Verification

The 0.151.0 npm package and Linux native package were fetched into temporary storage. The
native executable reported `codex-cli 0.151.0`; `codex exec --help` reported the upstream
`exec resume [OPTIONS] [SESSION_ID] [PROMPT]` contract. Every active critical-file and
semantic marker in `scripts/compat/upstream-baseline.json` was checked against the exact
peeled 0.151.0 commit with no missing markers.
